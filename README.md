# @cairnscale/uk-shop-payout-reconciler

Exact pence (`BigInt`) payout variance helper comparing **Shopify, WooCommerce, and Stripe** exports against **Xero or FreeAgent** postings — isolating unsplit gateway fees, missing orders, refunds, and duplicate imports.

Interactive local browser tool: [cairnscale.uk/tools/order-reconciliation/](https://cairnscale.uk/tools/order-reconciliation/)  
Methodology: [Shopify, WooCommerce & Stripe to Xero Matching (UK)](https://cairnscale.uk/guides/shopify-stripe-xero-reconciliation-uk/)

Built by [cairnscale](https://cairnscale.uk/services/xero-cis-reconciliation/) (MIT License).
