# @cairnscale/uk-shop-payout-reconciler

Exact BigInt integer-pence variance bridge reconciling **Shopify, WooCommerce, and Stripe** exports against **Xero or FreeAgent** postings — isolating unsplit merchant fees, missing orders, refunds, and duplicate imports.

Interactive zero-upload browser edition: [cairnscale.uk/tools/order-reconciliation/](https://cairnscale.uk/tools/order-reconciliation/)  
Full methodology: [Shopify, WooCommerce & Stripe to Xero Reconciliation (UK)](https://cairnscale.uk/guides/shopify-stripe-xero-reconciliation-uk/)
